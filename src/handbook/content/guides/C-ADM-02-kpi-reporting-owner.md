---
title: Set KPI reporting owner
---

## Steps

1. Open **KPI Performance** → **KPI settings** → **Reporting**.
2. Select **Reporting owner** (active user).
3. Set **launch date (IST)**.
4. Save.

## Expected outcome

Owner sees Daily DSAT module tasks from launch date forward.

## Common mistakes

- Setting owner without launch date (tasks stay off).
- Expecting Supervisors to configure this without `kpi.manage_goals`.
