---
title: Create an Agent QA review
---

## Steps

1. Go to **Quality Assurance** → **New review**.
2. Select an **Agent** as the subject.
3. Enter ticket reference and score each rubric criterion.
4. Save the review and notify the agent per team practice.

## Expected outcome

Review appears in QA list; agent can view and acknowledge.

## Common mistakes

- Scoring a non-Agent role as subject.
- Using retired supervisor validation workflow.
