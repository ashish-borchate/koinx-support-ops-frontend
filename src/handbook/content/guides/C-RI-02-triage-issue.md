---
title: Triage a reported issue
---

## Steps

1. Open **Reported Issues** filter **Pending Review** (Supervisor queue for resource-linked).
2. Set status **In Progress**, assign owner if needed.
3. Discuss via comments; @mention colleagues.
4. Resolve or set **No Action Required** with reason.

## Expected outcome

Issue reaches terminal status with audit trail in comments.

## Common mistakes

- Expecting automatic fixes to guide content without owner action.
