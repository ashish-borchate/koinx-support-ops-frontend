## Product Guides

1. Edit drafts or **Changes Required** content.
2. Complete **ready-to-publish** checklist (Mintlify confirmed).
3. **Publish** when status is Ready to Publish.
4. Complete **accuracy review** when due on Published guides.

Do not document Senior Agent **approve** steps—they are retired.

## Product Feedback

Review **Pending Review** submissions; approve or reject with clear context.

## Random QA audits

Supervisors spot-check Senior Agent QA evaluations for scoring accuracy.

1. Open an **Agent QA** evaluation (any age—there is no minimum wait) or review history under **QA → Random audits**.
2. Record **Accurate**, **Minor Issue Found**, or **Major Issue Found**.
3. For issues, write clear feedback for the **Senior Agent who performed the original evaluation** (never a stand-in name).
4. The Senior Agent **Acknowledges** or **Disagrees** via the QA detail page, dashboard attention, or module tasks.

Random audits **do not change** Agent QA scores or KPI. Score disputes use the **Agent appeal** workflow only.

## Senior Agent QA mode

Record QA on supervisor-handled cases when using **Senior Agent QA** mode—not the retired validation workflow.
