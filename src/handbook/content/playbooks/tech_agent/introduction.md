Tech Agents focus on **technical integration work** and **token migration acknowledgements** while viewing published knowledge.

## Responsibilities

- Complete **Integration Steps** frontend tasks when assigned.
- **Acknowledge token migrations** after being informed.
- View guides, integration tracker/library, Knowledge Base.
- Report issues when tooling or docs block you.

You generally do **not** enter KPI, create Agent QA, or publish product guides.
