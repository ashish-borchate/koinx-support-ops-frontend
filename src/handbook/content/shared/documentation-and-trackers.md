## Product Guides

Statuses: **Draft** → **Ready to Publish** → **Published**, plus **Changes Required** when updates are needed.

**Supervisors** drive ready-to-publish verification, publishing to Mintlify, and **accuracy review** on published guides. **Senior Agent approve/request-changes** steps are **retired**.

Agents may complete **daily guide review** tasks when assigned.

## Integration Steps

Tracks exchange integration documentation through review, Mintlify, optional frontend work, and **Completed**. Tech Agents handle **frontend** stages when assigned.

## Supported Files

Tracks whether exchange file support entries are **Verified** or **Needs Review**.

## Token Migration

Records migration events; Tech Agents **acknowledge** when informed.

## Feature Impact

Groups guides for a product change and shows rollout progress (not a substitute for per-guide accuracy review).

## Knowledge Base

Internal articles with **Active**, **Needs Update**, or **Archived**—separate from Product Guides and Integration Steps.
