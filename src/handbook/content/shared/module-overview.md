| Module | Purpose | Typical roles |
| --- | --- | --- |
| KPI Performance | Weekly/monthly agent metrics and scorecards | Supervisor entry; Agents view own; Admin configures goals |
| Quality Assurance | Ticket QA, appeals, random audits | Senior Agent creates; Agents view own |
| Coaching Center | Formal coaching with acknowledgement | Supervisors manage; Agents acknowledge |
| Negative Reviews | DSAT case tracking and coaching linkage | Supervisors/Senior manage; Agents acknowledge |
| Daily DSAT | Reporting owner records daily DSAT check (Mon–Sat IST) | Configured reporting owner (often Senior Agent) |
| Product Guides | Documentation lifecycle and publish | Supervisors publish; Agents daily review |
| Feature Impact | Rollout progress over linked guides | Supervisors manage |
| Integration Steps | Integration documentation workflow | Supervisors/Senior/Tech by stage |
| Supported Files | Exchange file verification | Supervisors verify; all roles may view tracker |
| Token Migration | Coin migration records + tech ack | Supervisors/Senior record; Tech acknowledges |
| Product Feedback | Agent submissions → supervisor review | Agents submit; Supervisors review |
| Knowledge Base | Long-form internal articles | Supervisors/Senior author; all view |
| Reported Issues | Internal issues on resources or operations | All create; Supervisors triage |
| Support Updates | Team announcements, optional ack | Supervisors/Admin post; all read |

Retired from the product (do not use): **Tasks**, **Hub Escalations**, **Support Actions**, standalone **Weekly** page, global **Audit** UI, **Freshdesk** admin in Hub.
