## Purpose
Formalize coaching with ownership, due dates, and agent acknowledgement.

## When to use it
You audit unassigned coaching or disputes — Supervisors own day-to-day coaching operations.

## Who is responsible
| Stage | Owner |
| --- | --- |
| Create / assign owner | Supervisor |
| Complete work | Coaching owner |
| Acknowledge | Agent |
| Dispute | Agent → Supervisor follow-up |

## What happens next
Pending → In Progress → Pending Acknowledgement → Completed (or Acknowledgement Disputed).

## What requires follow-up
- Unassigned coaching surfaces on **Supervisor** attention — assign an owner.

## Common mistakes
- Expecting QA closure to auto-complete coaching (link manually when needed).
