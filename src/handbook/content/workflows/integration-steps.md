## Purpose
Document exchange integrations through review, Mintlify, and tech frontend completion.

## When to use it
You oversee stuck integrations or clarify handoffs between Supervisor, Senior reviewer, and Tech Agent.

## Who is responsible
| Stage | Owner |
| --- | --- |
| Draft / manage | Supervisor |
| Pending Review | Assigned Senior Agent reviewer |
| Mintlify / publish steps | Supervisor |
| Pending Frontend | Assigned Tech Agent |

## What happens next
Draft → Pending Review → Mintlify states → Pending Frontend → Completed. Assignments drive dashboard attention.

## What requires follow-up
- Request changes on integration review is **active** (unlike retired PG senior approve).

## Common mistakes
- Confusing Integration review permissions with retired Product Guide senior review.
