## Purpose
Maintain the exchange supported-files matrix and verification state.

## When to use it
You audit Needs Review backlog on the dashboard module board.

## Who is responsible
Tracker updates: broad support access. Verification: Supervisor / Admin.

## What happens next
Files move between Verified and Needs Review — no cross-module automation.

## Common mistakes
- Expecting attention cards for every file (module tasks board instead).
